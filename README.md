# compliance-as-code-lab

Laboratorio para practicar Compliance as Code con OPA: controles de riesgo (SOX y no SOX) como políticas ejecutables con evidencia para auditoría, extendidos a MLOps y LLMOps.

- [Problema](docs/problema.md): qué se resuelve y cuándo está resuelto.
- [Caso de estudio](docs/caso_estudio.md): los retos para construirlo paso a paso.

Caso ficticio: las empresas, las personas y los datos son inventados.
